# 제목: 비트코인 결제와 기존 금융 지급결제의 구조적 차이 비교

## 부서명: 디지털서비스개발부
## 이름: 나림

-------------------

지급결제 시스템은 금융 인프라의 핵심 요소로, 거래를 생성하고 검증, 기록, 정산 과정을 통해 일련의 경제 활동을 가능하게 한다. 전통적인 금융 시스템은 은행과 카드사 같은 중앙기관이 운영하는 결제 인프라 위에서 작동하며, 사용자 계정의 **잔액**을 기반으로 거래를 처리한다. 반면 비트코인은 블록체인 기술을 기반으로 중앙기관 없이 거래를 기록하고 검증하는 새로운 구조를 제시하였다.

---

## 1. 기존 금융 지급결제 시스템 구조

기존 금융 지급결제 시스템은 중앙기관이 운영하는 **계정(Account) 기반 인프라** 위에서 작동한다. 예를 들어, 카드 결제 거래의 경우 다음과 같은 과정을 거친다.
```
사용자 → 가맹점 → 카드사 → 카드사 네트워크 → 은행 → 정산
```
이 시스템의 핵심 특징은 다음과 같다.

1. 거래 기록은 금융기관의 **중앙 데이터베이스**에 저장되며, 은행이나 카드사가 사용자 계정의 잔액을 관리하는 방식이다.

2. 금융기관 간에는 실제 자금 이동이 즉시 이루어지기보다 **결제 메시지 교환**을 통해 거래가 처리된다.

3. 거래 승인과 실제 정산이 분리되어 있다. 카드 결제는 즉시 승인되지만 실제 자금 이동은 일반적으로 시간이 지난 이후에 이루어진다.

사용자 잔액은 다음과 같이 기록된다.
```
Account #12345
Name: Alice
Balance: $100
```
즉, 기존 금융의 계정 기반 모델에서는 **사용자의 전체 잔액 상태만을 기록**하며, 잔액이 어떤 거래로 구성되었는지는 별도로 추적하지 않는다.

---

## 2. 비트코인 결제 인프라 구조

비트코인은 중앙기관이 아닌 **분산 네트워크 기반 지급결제 시스템**이다. 거래는 금융기관을 거치지 않고 P2P 네트워크를 통해 전파되며, 네트워크 노드들이 이를 검증한다.

비트코인의 기본 거래 흐름은 다음과 같다.
```
사용자 → P2P 네트워크 → 노드 검증 → 블록 생성 → 블록체인 기록
```
이 구조의 특징은 다음과 같다.

1. 거래 기록은 특정 기관의 서버가 아니라 **분산 원장(Distributed Ledger)** 에 저장된다.

2. 중앙 관리자가 아닌 네트워크에 참여한 참여자들이 직접 거래를 검증하는 **P2P 구조**를 사용한다.

3. 거래 기록과 정산이 하나의 과정으로 통합되어 있다. 거래가 블록에 포함되고 블록이 확정(채굴)되면 해당 거래는 사실상 최종 정산 상태에 도달한다.

즉 비트코인은 **네트워크 자체가 결제 시스템 역할을 수행하는 구조**라고 볼 수 있다.

---

## 3. UTXO 모델과 Account 모델의 차이

비트코인과 기존 금융 시스템의 가장 중요한 기술적 차이 중 하나는 **사용자 잔액을 추적하는 방식**이다.

기존 금융 시스템과 이더리움은 **Account-based model**을 사용한다. 이 모델에서는 계정의 전체 잔액을 하나의 상태로 관리한다. 예를 들어 Alice가 Bob에게 5달러를 보내면 다음과 같이 계정 잔액이 수정된다.

```
Alice: 60 → 55
Bob: 20 → 25
```
반면 비트코인은 **UTXO(Unspent Transaction Output) 모델**을 사용한다.

UTXO는 "사용되지 않은 트랜잭션 출력값"을 의미하며, 비트코인 네트워크는 사용자의 잔액을 하나의 숫자로 기록하지 않는다. 대신 사용자가 사용할 수 있는 여러 개의 UTXO 집합으로 잔액을 관리한다.

예를 들어 Alice가 Bob에게 5 BTC를 보내면, Bob은 **5 BTC 가치의 UTXO**를 받게 된다. 이 UTXO는 이후 Bob이 새로운 거래를 만들 때 입력(input)으로 사용된다.

즉 사용자의 잔액은 다음과 같이 표현된다.
```
Bob의 잔액 = 여러 개의 UTXO의 합
```
이 모델의 특징은 다음과 같다.

- 하나의 UTXO는 한 번만 사용할 수 있다.
- 거래가 발생하면 기존 UTXO는 소비되고 새로운 UTXO가 생성된다.
- 사용자의 UTXO는 여러 블록에 분산되어 존재할 수 있다.

따라서 사람들이 흔히 "3 BTC를 가지고 있다"고 말하지만, 기술적으로는 **"3 BTC를 사용할 수 있는 UTXO들을 가지고 있다"** 는 의미가 된다.

---

## 4. 구조적 차이 정리

기존 금융 시스템과 비트코인의 지급결제 구조 차이를 정리하면 다음과 같다.

| 구분 | 기존 금융 시스템 | 비트코인 |
|-----|------------------|----------|
| 원장 구조 | 중앙 데이터베이스 | 분산 원장 |
| 잔액 추적 방식 | Account Model | UTXO Model |
| 네트워크 구조 | 기관 중심 네트워크 | P2P 네트워크 |
| 정산 방식 | 별도 정산 과정 | 블록 확정 |

---

## 5. 결론

비트코인은 단순한 디지털 화폐라기보다 **지급결제 인프라의 구조를 새롭게 설계한 기술**이라고 볼 수 있다.

기존 금융 시스템은 중앙기관이 계정을 관리하는 방식으로 결제를 처리하지만, 비트코인은 분산 네트워크와 UTXO 모델을 통해 사용자 잔액을 추적하고 거래를 기록한다. 이러한 구조는 기존 금융 시스템과는 다른 방식으로 거래 상태를 관리하는 새로운 결제 인프라의 가능성을 보여준다.

따라서 비트코인은 기존 금융 시스템을 완전히 대체하기보다는, **지급결제 인프라 설계의 또 다른 기술적 접근 방식**을 제시한 사례로도 이해할 수 있다.
